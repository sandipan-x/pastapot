# PastaPot

Get perfect pasta every time with the 100g pasta, 1L water, 10g salt rule. Scale servings instantly and find the best sauce pairing for your pasta shape.

## Features
- Servings scaler with the 100g pasta / 1L water / 10g salt rule
- Pasta shape picker with cooking times and sauce pairing suggestions
- Visual pot-fill guide showing how full your pot will be
